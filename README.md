## 🚀 Lab 01 Overview

Lab 01 covers:
- Initializing a Node.js project using npm and understanding `package.json`.
- Creating a basic web server using the built-in `http` module (`basic-server.js`).
- Building a modular web server using Express.js (`server.js`).
- Implementing REST endpoints:
  - `GET /` - Welcome message
  - `GET /about` - Student profile (JSON)
  - `GET /time` - Server timestamp (JSON)
  - `GET /*` - Catch-all 404 handler (JSON)
- Output verification with captured screenshots.
